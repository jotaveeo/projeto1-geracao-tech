
# Projeto 1 - Geração Tech

Site em HTML e CSS, utilizando Flexbox e Grid.

## Descrição

Este projeto consiste em um site desenvolvido como parte do programa Geração Tech. O objetivo é praticar e demonstrar conhecimentos em HTML e CSS, aplicando principalmente técnicas de layout moderno como Flexbox e CSS Grid.

## Funcionalidades

- Layout responsivo
- Estrutura com Flexbox e Grid
- Design moderno e adaptável a diferentes dispositivos
- Código limpo e organizado

## Tecnologias Utilizadas

- HTML5
- CSS3 (Flexbox e Grid)

## Como Executar

1. Clone o repositório:
   ```bash
   git clone https://github.com/jotaveeo/projeto1-geracao-tech.git
   ```
2. Acesse a pasta do projeto:
   ```bash
   cd projeto1-geracao-tech
   ```
3. Abra o arquivo `index.html` no seu navegador preferido.
